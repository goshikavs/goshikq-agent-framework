---
title: Python SDK
description: Install and use the unpublished goshikq-ai Python SDK from source.
---

The Python package in this tree is `goshikq-ai` 1.0.1. It is **not published to PyPI**. Install from source. It talks to the [`v1.0.0`](https://github.com/goshikavs/goshikq-agent-framework/releases/tag/v1.0.0) runtime. A 1.0.x SDK may use a 1.0.x runtime while the protocol schema stays `1.0`. `v1.0.0-rc.1` is superseded due to its older JWT dependency. `v1.0.0-rc.2` remains published.

```bash
python -m pip install -e sdk/python
```

Optional extras (experimental paid providers):

```bash
python -m pip install -e "sdk/python[openai]"
python -m pip install -e "sdk/python[anthropic]"
```

Quickstart uses `MockModel` and does not need those extras.
