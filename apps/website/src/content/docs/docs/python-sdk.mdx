---
title: Python SDK
description: Install and use the unpublished goshikq-ai Python SDK from source.
---

The Python package is `goshikq-ai` version `1.0.0rc2` in this tree. It is **not published to PyPI**. Install from source. Native runtime archives on GitHub remain the [`v1.0.0-rc.1`](https://github.com/goshikavs/goshikq-agent-framework/releases/tag/v1.0.0-rc.1) prerelease until rc.2 is tagged.

```bash
python -m pip install -e sdk/python
```

Optional extras (experimental paid providers):

```bash
python -m pip install -e "sdk/python[openai]"
python -m pip install -e "sdk/python[anthropic]"
```

Quickstart uses `MockModel` and does not need those extras.
