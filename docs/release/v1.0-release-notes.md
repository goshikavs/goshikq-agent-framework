# v1.0.0-rc.1 release notes (draft)

**Status: not tagged, not published.** In-tree versions are Cargo/npm `1.0.0-rc.1` and Python `1.0.0rc1`.  
PR https://github.com/goshikavs/goshikq-agent-framework/pull/27.

This is a **release candidate**. It is not stable v1.0.

## Intent

First release candidate for Goshikq: durable agent execution plus authoritative outcome verification.

## Headline

Build Agents. Verify Outcomes.

A successful tool call is not a verified business result.

## In this candidate (engineering)

- Package versions aligned per ecosystem (Cargo/npm SemVer prerelease vs PEP 440)
- sqlx 0.9 (PostgreSQL only). `rsa` / Marvin removed from `Cargo.lock`
- DOMPurify 3.4.17 override for Studio; bun audit is a required gate
- Native debug CI on Windows x64, Linux x64, Linux ARM64, macOS Intel, macOS ARM64 (plus experimental Windows ARM64)
- Release-candidate workflow: `--release` archives, packaged-binary smoke, SHA256SUMS, SPDX SBOM, isolated SDK packs — **no** git tag or GitHub Release
- Bank, travel, and enterprise sandbox examples with evidence-aware goals
- Adversarial tests: model text and processor acks cannot mint VERIFIED
- Python 3.11–3.13 unit matrix
- Docker compose smoke on linux/amd64 and linux/arm64

## Not in this candidate

- Published packages (crates.io / PyPI / npm)
- A public GitHub Release or `v1.0.0-rc.1` tag (owner command sheet: `docs/release/v1.0-owner-publish.md`)
- Claimed performance vs Temporal / DBOS / Restate / LangGraph
- Compliance certifications
- Automatic retention GC
- Temporal integration
- Hosted IdP certification

## Install (from source until the owner publishes)

```bash
git clone https://github.com/goshikavs/goshikq-agent-framework.git
python -m pip install -e sdk/python
cargo run -p goshikq-server
python examples/hello-agent/main.py
```

After owner publication, use the GitHub Release archives and `SHA256SUMS` instead of `cargo run`.
