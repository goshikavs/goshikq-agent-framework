## Windows ARM64 is experimental

`goshikq-1.0.0-rc.1-windows-arm64.zip` is **not** a v1.0 required platform.

- The `windows-11-arm` job uses `continue-on-error`. A later red job there does not fail the required matrix.
- Packaged smoke passed on this candidate (RC job 135708483093) and the zip contains `EXPERIMENTAL.txt`. That is one runner, not a production support claim.
- Embedded PostgreSQL downloads Theseus on first `DATABASE_URL=embedded` start (all platforms). On Windows, leftover postgres listeners can survive a naive process stop.
- A Windows ARM64 **host** building x64 via `scripts/with-msvc.ps1` is not this native ARM64 archive.
- Prefer Windows AMD64, Linux AMD64/ARM64, or macOS Intel/Apple Silicon.

GitHub prerelease body (when the owner publishes): `docs/release/v1.0.0-rc.1-github-prerelease.md`.

## Not in this candidate

- Published packages (crates.io / PyPI / npm)
- A public GitHub Release or `v1.0.0-rc.1` tag until the owner publishes — commands: `docs/release/v1.0-owner-publish.md`
- Claimed performance vs Temporal / DBOS / Restate / LangGraph. Crash-recovery latency remains **NOT_RUN**.
- Hosted identity-provider interoperability (Entra / Keycloak / Auth0) is not certified
- Live LLM tests unless `GOSHIKQ_LIVE_LLM=1` (this candidate used the mock model)
- Compliance certifications
- Automatic retention GC
- Temporal integration

## Install (from source until the owner publishes)

```bash
git clone https://github.com/goshikavs/goshikq-agent-framework.git
python -m pip install -e sdk/python
cargo run -p goshikq-server
python examples/hello-agent/main.py
```

After owner publication, download the GitHub prerelease archives and check `SHA256SUMS`.
