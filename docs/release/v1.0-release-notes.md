## Intent

First release candidate for Goshikq: durable agent execution plus authoritative outcome verification.

## Headline

Build Agents. Verify Outcomes.

A successful tool call is not a verified business result.

## In this candidate

- Package versions aligned per ecosystem (Cargo/npm `1.0.0-rc.1`, Python PEP 440 `1.0.0rc1`)
- sqlx 0.9 (PostgreSQL). `rsa` / Marvin removed from `Cargo.lock`
- DOMPurify 3.4.17 and related bun overrides; bun audit is a required gate
- Release-profile archives smoked on Windows x64, Linux x64, Linux ARM64, macOS Intel, macOS ARM64 (Windows ARM64 experimental also smoked)
- SHA256SUMS and SPDX SBOM staged as CI artifacts
- Isolated Python/TypeScript SDK installs against a `--release` runtime
- Adversarial tests: model text and processor acks cannot mint VERIFIED

## Not in this candidate

- Published packages (crates.io / PyPI / npm)
- A public GitHub Release or `v1.0.0-rc.1` tag — owner commands: `docs/release/v1.0-owner-publish.md`
- Claimed performance vs Temporal / DBOS / Restate / LangGraph
- Compliance certifications
- Automatic retention GC
- Temporal integration
- Hosted IdP certification

## Install (from source until the owner publishes)

```bash
git clone https://github.com/goshikavs/goshikq-agent-framework.git
python -m pip install -e sdk/python
cargo run -p goshikq-server
python examples/hello-agent/main.py
```

After owner publication, download the GitHub prerelease archives and check `SHA256SUMS`.
