# v1.0.0-rc.1 release notes (draft)

**Status: not tagged, not published.** Package versions remain `0.1.0-alpha`.

## Intent

First release candidate for Goshikq: durable agent execution plus authoritative outcome verification.

## Headline

Build Agents. Verify Outcomes.

A successful tool call is not a verified business result.

## In this candidate (engineering, untagged)

- Cross-platform native CI definitions for Windows x64, Linux x64, Linux ARM64, macOS Intel, macOS ARM64
- Windows ARM64 experimental job
- rustfmt + clippy required job
- Bank, travel, and enterprise sandbox examples with evidence-aware goals
- Adversarial tests: model text and processor acks cannot mint VERIFIED
- Migration file inventory test
- Python 3.11–3.13 unit matrix
- Native linux/arm64 Docker smoke job

## Not in this candidate

- Published packages
- GitHub Release binaries
- Claimed performance vs Temporal / DBOS / Restate / LangGraph
- Compliance certifications
- Automatic retention GC
- Temporal integration
- Hosted IdP certification

## Install (from source only)

```bash
git clone https://github.com/goshikavs/goshikq-agent-framework.git
python -m pip install -e sdk/python
cargo run -p goshikq-server
python examples/hello-agent/main.py
```
