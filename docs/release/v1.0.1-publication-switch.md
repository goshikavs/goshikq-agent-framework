# v1.0.1 publication switch

Do not perform this switch until `goshikq-ai` 1.0.1 is on PyPI and `@goshikq/sdk` 1.0.1 is on npm. Until then the website and README keep source-install commands, and the public runtime stays GitHub Release v1.0.0.

The workspace version on this branch is `1.0.1`. `goshikq --version` and the `/health` `version` field both read `CARGO_PKG_VERSION`, so a release built from this source reports `1.0.1`. Protocol `SCHEMA_VERSION` stays `1.0`. The public installer still downloads GitHub Release v1.0.0, whose binaries report `1.0.0`. Do not retag or replace those binaries.

A GitHub Release named v1.0.1 is a separate owner action after merge. Tag a commit that is on `main`. Do not attach artifacts built from the pull request's synthetic merge ref. Do not point the website or `scripts/install.sh` at `v1.0.1` until that release and its `SHA256SUMS` exist. When they do, change the installer default and the website asset URLs together, then run the installer smoke against the new archives.

## After the SDK uploads succeed

1. In `apps/website/src/lib/site.ts`, set `pythonVersion` and `tsVersion` to `1.0.1`. Leave `version` and the v1.0.0 release URLs unchanged unless a new runtime release exists.
2. In `scripts/assert_rc_versions.py`, change the website checks that currently require those two fields to stay `1.0.0`.
3. On the install page, the homepage install tabs (`apps/website/src/components/InstallJourney.astro`), the README quick start, getting started, and `docs/guides/installation.md`, add the registry commands next to the source commands only after a clean install of each published package succeeds:
   - `python -m pip install goshikq-ai==1.0.1`
   - `npm install @goshikq/sdk@1.0.1`
4. Keep the runtime installer on `v1.0.0` until a v1.0.1 GitHub Release and its SHA256SUMS exist.
5. Deploy the website from `main` with `docs.yml`. Confirm the live install page shows the new commands and still labels v1.0.0 as the stable runtime if no new archives were published.

## Do not

- Re-upload v1.0.0 archives.
- Point download links at a tag that has no release assets.
- Dispatch the publish workflows before the trusted-publisher environments exist.
