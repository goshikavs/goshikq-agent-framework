# v1.0.1 release notes (not tagged)

This patch is prepared and not released. The stable GitHub Release remains [v1.0.0](https://github.com/goshikavs/goshikq-agent-framework/releases/tag/v1.0.0), built from `83bc8e71edf46a20986f2380309e3d74d0ff3ab9`.

## What the patch contains

- Installation pages and a README quick start that separate the v1.0.0 runtime from the source SDK install.
- Python `goshikq-ai` 1.0.1 and TypeScript `@goshikq/sdk` 1.0.1 prepared for publication. Neither package is on a registry.
- Trusted-publishing workflows that run only by manual dispatch, only for a tag already on `main`, and only when that version is absent from the registry.
- An installer smoke workflow that runs `scripts/install.sh` and `scripts/install.ps1` against the published v1.0.0 archives.

## API

No public SDK export used by the v1.0.0 examples is removed or renamed. Protocol `SCHEMA_VERSION` stays `1.0`. SDK 1.0.1 is compatible with runtime 1.0.0. The compatibility table is `docs/release/sdk-compatibility.md`.

## Security scans

CI job `security-scans` runs Gitleaks, `cargo audit`, and `pip-audit` on the pull request. Those results belong to the commit they ran on. Repeat them on the final `main` commit before tagging.
