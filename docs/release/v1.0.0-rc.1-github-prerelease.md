## Windows ARM64 is experimental

The file `goshikq-1.0.0-rc.1-windows-arm64.zip` (SHA256 `c318493c2a59117ecf11c8a6427ce334dd4346e396ce268189afbfd11659b106`) is **experimental**. It is **not** a v1.0 required platform.

Known limitations:

- The `windows-11-arm` GitHub Actions job uses `continue-on-error`. A later failure on that runner does not fail the required release matrix.
- Packaged smoke **did** pass on this candidate (job 135708483093), including `/ready`, hello-agent VERIFIED, echo COMPLETED, shutdown, and restart recovery. That is one runner, not a production support claim.
- The archive includes `EXPERIMENTAL.txt`. Do not deploy it as a supported production runtime.
- Embedded PostgreSQL (`DATABASE_URL=embedded`) downloads Theseus binaries from GitHub on first start (all platforms). Windows operators must stop leftover postgres listeners; a naive process kill can leave port 5432/Theseus still bound.
- A Windows ARM64 **host** compiling with x64 MSVC (`scripts/with-msvc.ps1`) is a different configuration from this native `aarch64-pc-windows-msvc` archive.
- No musl, 32-bit, Android, or iOS claim.

Prefer Windows AMD64, Linux AMD64/ARM64, or macOS Intel/Apple Silicon for this candidate.

## Install (native archive)

Unix:

```sh
tar -xzf goshikq-1.0.0-rc.1-linux-amd64.tar.gz
cd goshikq-1.0.0-rc.1-linux-amd64
chmod +x goshikq-server goshikq
export DATABASE_URL=embedded
export GOSHIKQ_AUTH_MODE=none   # development only
./goshikq-server
```

Windows (cmd), AMD64:

```bat
tar -xf goshikq-1.0.0-rc.1-windows-amd64.zip
cd goshikq-1.0.0-rc.1-windows-amd64
set DATABASE_URL=embedded
set GOSHIKQ_AUTH_MODE=none
goshikq-server.exe
```

Health: `http://127.0.0.1:7400/health` and `/ready`. Production must use a real `DATABASE_URL` and must not use `GOSHIKQ_AUTH_MODE=none`.

Python `goshikq-ai==1.0.0rc1` and TypeScript `@goshikq/sdk@1.0.0-rc.1` are **not** on PyPI or npm. Install from source:

```bash
git clone https://github.com/goshikavs/goshikq-agent-framework.git
python -m pip install -e sdk/python
```

## Not in this prerelease

- crates.io / PyPI / npm publication. Python `goshikq-ai` and TypeScript `@goshikq/sdk` are **not** on registries; install from source.
- Stable `v1.0.0`
- Hosted identity-provider interoperability (Entra / Keycloak / Auth0) is **not** certified. OIDC JWKS tests cover issuer, audience, expiry, rotation, and algorithm restrictions in CI; they are not a hosted IdP certification.
- Live LLM tests are skipped unless `GOSHIKQ_LIVE_LLM=1`. This candidate was smoked with the mock model.
- Performance: GitHub-hosted `/health` and echo-workflow numbers exist for a debug CI runtime; crash-recovery latency and load tables are **NOT_RUN**. There is no comparison to Temporal / DBOS / Restate / LangGraph and no product SLA.
- SOC 2 / HIPAA / PCI
- Automatic retention GC, Temporal integration
