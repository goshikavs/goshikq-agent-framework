# v1.0 security review

Status: **PASS with residual risk** pending green CI on this RC commit. Not a certification. No SOC 2 / HIPAA / PCI claim.

Tree versions: Cargo/npm `1.0.0-rc.1`, Python `1.0.0rc1`. Not published.

## Controls present in code

- OIDC JWKS RS256: issuer, audience, expiry, `kid` refresh, HMAC rejected unless loopback test flag
- API keys with rotate/revoke/expiry
- RBAC + project membership; storage queries filter `project_id`
- Studio proxy does not put API keys in the browser (Playwright security specs exist)
- Secret redaction before persist/export (`goshikq-core` redaction)
- A2A message size cap; untrusted remote verification ignored
- MCP tools allowlisted; stdio subset
- High-risk tools can require approval and evidence contracts
- Retention purge is owner-only, dry-run default
- `GOSHIKQ_AUTH_MODE=none` is development/CI only

## Unmaintained crates (warnings, not ignored)

| Crate | Why present | Risk | Upgrade plan |
| --- | --- | --- | --- |
| `chrono` 0.4 | Workspace datetime type; sqlx `chrono` feature | Maintainer capacity; no current RUSTSEC vulnerability on the used surface | Stay on 0.4 until a chrono 0.5 / `jiff`/`time` migration is scoped after v1.0 stable. Do not pretend an upgrade was done |

Do not `ignore` unmaintained advisories. cargo-audit may warn; CI fails on vulnerabilities except the documented sqlite lockfile leftover.

## Known residual risk

- Prompt injection is not solved
- Hosted IdP (Entra/Keycloak/Auth0) not interoperability-tested
- SSRF via user-controlled tool URLs is an application concern; the runtime does not fetch arbitrary URLs for agents
- Rate limit: OTLP limiter exists; general HTTP rate limit is not a full WAF
- Unmaintained `chrono`/`paste`/`pin-utils` (plan above)
- Monaco still vendors an editor; override pins DOMPurify 3.4.17 until monaco-editor bumps
