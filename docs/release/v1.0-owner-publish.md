# Owner commands: publish v1.0.0-rc.1

Do **not** run these until the owner explicitly approves a public RC tag and GitHub prerelease.

These commands do not publish crates.io, PyPI, or npm. Registry publication needs a second, separate authorization.

Assume `COMMIT` is the validated release-candidate SHA for the **binaries**:

`1f4d35dd6b73801ede2ec1e64ad906645c4d7a60`

(see `docs/release/v1.0-artifact-manifest.md` and `docs/release/v1.0-publication-manifest.md`). Do not tag a later docs-only SHA if you intend those exact archives.

```bash
git fetch origin
git checkout 1f4d35dd6b73801ede2ec1e64ad906645c4d7a60
git tag -a v1.0.0-rc.1 1f4d35dd6b73801ede2ec1e64ad906645c4d7a60 -m "Goshikq v1.0.0-rc.1"
git push origin v1.0.0-rc.1
```

Download the native archives, LF `SHA256SUMS`, and SBOM from https://github.com/goshikavs/goshikq-agent-framework/actions/runs/44565620547 (or reuse `%TEMP%\goshikq-preflight-1f4d35d\attach` after preflight). Rename the SPDX file to `goshikq-1.0.0-rc.1.spdx.json`. Verify checksums after download:

```bash
sha256sum -c SHA256SUMS
```

Create a **prerelease** (not latest stable). Attach Windows ARM64; it smoked successfully and is labeled experimental in the notes:

```bash
gh release create v1.0.0-rc.1 \
  --target 1f4d35dd6b73801ede2ec1e64ad906645c4d7a60 \
  --prerelease \
  --title "v1.0.0-rc.1" \
  --notes-file docs/release/v1.0.0-rc.1-github-prerelease.md \
  goshikq-1.0.0-rc.1-linux-amd64.tar.gz \
  goshikq-1.0.0-rc.1-linux-arm64.tar.gz \
  goshikq-1.0.0-rc.1-macos-amd64.tar.gz \
  goshikq-1.0.0-rc.1-macos-arm64.tar.gz \
  goshikq-1.0.0-rc.1-windows-amd64.zip \
  goshikq-1.0.0-rc.1-windows-arm64.zip \
  SHA256SUMS \
  goshikq-1.0.0-rc.1.spdx.json \
  goshikq-1.0.0-rc.1-license-inventory.md
```

Python / npm / crates.io remain unpublished until a separate owner decision.

Stable `v1.0.0` is a different approval. Do not retitle this prerelease as latest stable. Website and README must keep **release candidate** language after this publish.
