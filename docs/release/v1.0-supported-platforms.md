# Supported platforms (v1.0 engineering)

Classifications:

- **TESTED** — native tests executed on that OS/arch in this cycle (local or GitHub Actions). A URL or log is required.
- **BUILD_ONLY** — compiled (possibly cross) without native execution evidence.
- **EXPERIMENTAL** — attempted; not a release gate.
- **UNSUPPORTED** — not claimed.

A cross-compiled binary is not TESTED.

## Embedded PostgreSQL

`postgresql_embedded` (Theseus) is the no-Docker local path (`DATABASE_URL=embedded`). Native smoke jobs use it so macOS/Windows runners do not require a Postgres service container.

If Theseus has no binary for a target, that job must fail or skip honestly — do not mark TESTED.

## Cost note

Private repositories consume GitHub Actions minutes for all of the above, including macOS and ARM. This is allowed by the v1.0 prompt; it is not a paid third-party service purchase.
