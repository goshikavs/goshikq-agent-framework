## Embedded PostgreSQL

`postgresql_embedded` (Theseus) is the no-Docker local path (`DATABASE_URL=embedded`). Native smoke jobs use it.

Fixes recorded this cycle:

- sqlx sends startup `TimeZone=UTC`. Hosts without a usable Olson UTC (Ubuntu 26.04 tzdata split, some macOS images) rejected the parameter. The server now seeds a TZif UTC file into the Theseus install tree; CI also writes `/usr/share/zoneinfo/UTC` on Unix runners.
- Theseus lists GitHub releases via `api.github.com`. Unauthenticated hosted-runner IPs returned **403**. Native jobs now pass `GITHUB_TOKEN`.

If Theseus has no binary for a target, that job must fail — do not mark TESTED.

## Limitations

- TESTED means the CI debug binary started and ran hello-agent. It is **not** a hashed release-profile installer.
- Windows ARM64 authoring hosts that cross-compile x64 MSVC are not a substitute for the `windows-latest` job.
- No musl, 32-bit, or Android/iOS claim.
