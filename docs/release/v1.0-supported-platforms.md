# Supported platforms (v1.0 engineering)

Classifications:

- **TESTED** — native tests executed on that OS/arch in this cycle (local or GitHub Actions). A URL or log is required.
- **BUILD_ONLY** — compiled (possibly cross) without native execution evidence.
- **EXPERIMENTAL** — attempted; not a release gate.
- **UNSUPPORTED** — not claimed.

A cross-compiled binary is not TESTED.

Debug-runtime evidence (not RC packages): https://github.com/goshikavs/goshikq-agent-framework/actions/runs/44456912020 on `d1ebe67`.

Release-profile archive evidence: PENDING_CI (`.github/workflows/release-candidate.yml`).

## Embedded PostgreSQL

`postgresql_embedded` (Theseus) is the no-Docker local path (`DATABASE_URL=embedded`). Native smoke jobs use it. First start downloads Postgres from GitHub (`GITHUB_TOKEN` in CI).

## Limitations

- Historical TESTED rows are **debug** binaries. Release-candidate install tests must use the packaged `--release` archives.
- Windows ARM64 authoring hosts that cross-compile x64 MSVC are not a substitute for `windows-latest`.
- No musl, 32-bit, or Android/iOS claim.
