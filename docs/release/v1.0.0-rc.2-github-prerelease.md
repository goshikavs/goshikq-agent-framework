## Upgrade from v1.0.0-rc.1

1. Verify `SHA256SUMS` for the rc.2 archives (not the rc.1 checksums).
2. Replace `goshikq-server` / `goshikq` with the rc.2 archive for your platform. Keep the same `DATABASE_URL`.
3. JWT validation is stricter: string `exp`/`nbf` and missing `exp`/`iss`/`aud`/`sub` are rejected. Numeric registered claims from Entra/Keycloak/Auth0 are unchanged in intent.
4. HMAC loopback test mode is still `GOSHIKQ_OIDC_ALLOW_TEST_HMAC`. Production must not use `GOSHIKQ_AUTH_MODE=none`.

## Install (native archive)

Unix:

```sh
tar -xzf goshikq-1.0.0-rc.2-linux-amd64.tar.gz
cd goshikq-1.0.0-rc.2-linux-amd64
chmod +x goshikq-server goshikq
export DATABASE_URL=embedded
export GOSHIKQ_AUTH_MODE=none   # development only
./goshikq-server
```

Windows (cmd), AMD64:

```bat
tar -xf goshikq-1.0.0-rc.2-windows-amd64.zip
cd goshikq-1.0.0-rc.2-windows-amd64
set DATABASE_URL=embedded
set GOSHIKQ_AUTH_MODE=none
goshikq-server.exe
```

Health: `http://127.0.0.1:7400/health` and `/ready`.

Python `goshikq-ai==1.0.0rc2` and TypeScript `@goshikq/sdk@1.0.0-rc.2` are **not** on PyPI or npm. Install from source:

```bash
git clone https://github.com/goshikavs/goshikq-agent-framework.git
git checkout 07b0abd56bc84fc78532bc2ce8de2c14de9cf29b
python -m pip install -e sdk/python
```
