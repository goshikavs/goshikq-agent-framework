# v1.0 API compatibility

Package versions in tree are Cargo/npm `1.0.0-rc.1` and Python `1.0.0rc1`. No git tag or registry publish until owner approval.

## Runtime HTTP

- Base: `http://127.0.0.1:7400`
- OpenAPI export: `goshikq-server --export-openapi docs/api/openapi.json`
- Protocol worker version: see `sdk/python/src/goshikq_ai/_version.py` and TypeScript SDK
- Auth: `GOSHIKQ_AUTH_MODE=none|oidc`. Production must not use `none`.

## Compatibility guarantees proposed for v1.0 stable (not in force until tag)

1. sqlx migrations are append-only. Already-applied files are not edited.
2. Run status strings remain parseable including `BUDGET_EXCEEDED` alias.
3. `OutcomeContract` fields stay independent: tool success is not goal verification.
4. Source-framework labels `goshikq-python` / `goshikq-workflow` / `langgraph` continue to round-trip.
5. Dual-read of `GOSHIKQ_*` / legacy `AXIOM_*` env vars remains until a later major.

## Breaking vs alpha

Alpha never promised a stable HTTP or SDK surface. A v1.0.0 tag would freeze the exported OpenAPI for the 1.x series with additive changes only. That freeze is **not** in effect yet.
