## What the code actually implements

Available (code + tests exist; not all re-run in this document yet):

- Rust runtime (`goshikq-server`) with Tokio, PostgreSQL (sqlx migrations 0001–0009), embedded Postgres option
- Durable recovery: checkpoints, action journal, leases, crash barriers (`GOSHIKQ_CRASH_AT`)
- Goal verification against `StateSnapshot`; processor accept ≠ settled
- Evidence graphs, coverage contracts, stale-approval invalidation
- Multi-agent parent/child, A2A JSON-RPC subset, MCP stdio subset
- Workflow graphs executed by Rust; Studio React Flow editor does not schedule
- Human approvals + Studio queue
- Python SDK worker loop; TypeScript SDK worker protocol
- OIDC JWKS (RS256) + API keys + RBAC + project isolation
- Native OTLP export (redacted JSON); inbound OTLP from foreign runtimes stays UNVERIFIED
- Goshikq Studio (Next.js 15)
- Docker Compose runtime + studio profiles
- Public website (Astro Starlight) in `apps/website` — not production-hosted
- VitePress GitHub Pages still the live docs host if enabled

Experimental:

- OpenAI / Anthropic adapters (paid keys)
- MCP Streamable HTTP (stdio only in tree)
- A2A remote SUCCESS ≠ parent VERIFIED
- Studio Tools / Goals / Evaluations / Regression / Benchmarks nav (“soon”)

Deferred / unsupported as of this audit:

- Temporal integration
- Automatic retention GC (admin purge only)
- Published packages and container registry
- Hosted IdP interoperability
- Compliance certifications
