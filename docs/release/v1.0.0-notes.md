# v1.0.0 — prepared, not published

**Status: not a GitHub Release.** Do not tag `v1.0.0` from this file. Public downloads stay [`v1.0.0-rc.2`](https://github.com/goshikavs/goshikq-agent-framework/releases/tag/v1.0.0-rc.2). `v1.0.0-rc.1` remains published and superseded.

## What changes from rc.2

- Package metadata is stable `1.0.0` (Python `1.0.0`). The rc.2 tag and binaries are unchanged.
- `COMPLETED` does not mean `VERIFIED`. Verification is written only with an accepted goal check in the same lease-fenced update.
- A stale lease holder cannot persist `VERIFIED` after another worker wins the lease.
- `url` 2.5.9 (`RUSTSEC-2026-0592`). `jsonwebtoken` remains 12.0.0.

## Upgrade

Install the published rc.2 archive until `v1.0.0` exists. After the owner publishes the stable tag, download the new archive and `SHA256SUMS`, check the hash, and replace the extracted binaries. Do not delete the rc.1 or rc.2 releases. SDK packages are still installed from source. They are not on PyPI or npm.

## Known limitations

- Verification is point-in-time. A later external change does not rewrite a historical `VERIFIED` row.
- Exactly-once external effects are not promised without an idempotency key the external API honors.
- Prompt injection is not solved.
- Windows ARM64 is experimental.
- Unmaintained-crate warnings remain for `chrono`, `paste`, and `pin-utils`.
- `GOSHIKQ_AUTH_MODE=none` is for local development.
