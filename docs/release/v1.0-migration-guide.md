# v1.0 migration guide (alpha → future 1.0)

This is not an upgrade from a published 1.0. Operators on local alpha databases:

## Fresh install

```bash
git clone https://github.com/goshikavs/goshikq-agent-framework.git
# PostgreSQL: docker compose up -d postgres
# or: DATABASE_URL=embedded
cargo run -p goshikq-server
# migrations run on start
```

## Existing alpha schema

Migrations `0001`–`0009` are forward-only. The runtime applies missing versions at startup.

Do **not** hand-edit rows in `_sqlx_migrations` or change checksums of applied files.

Rollback: restore a PostgreSQL backup taken before the upgrade. There is no automated down-migration.

## Backup / restore

```bash
pg_dump "$DATABASE_URL" > goshikq.dump.sql
psql "$DATABASE_URL" < goshikq.dump.sql
```

Embedded Theseus data directories are local files under `.goshikq/` or `.axiom/` (legacy). Copy the directory only when the server is stopped.

## SDK

Reinstall from source after pull. Wheel/tarball isolated-install tests live in `tests/packaging`.
