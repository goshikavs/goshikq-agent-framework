## Upgrade from v1.0.0-rc.1 (after rc.2 is tagged)

1. Verify the new `SHA256SUMS` against the rc.2 GitHub prerelease (not this document until that tag exists).
2. Replace `goshikq-server` / `goshikq` with the rc.2 archive for your platform.
3. Keep the same `DATABASE_URL`. JWT validation is stricter: string `exp`/`nbf` and missing `exp`/`iss`/`aud`/`sub` are rejected. Legitimate OIDC tokens from Entra/Keycloak/Auth0 already use numeric registered claims.
4. HMAC loopback test mode is unchanged (`GOSHIKQ_OIDC_ALLOW_TEST_HMAC`).
