# After v1.0.0 is published

Do not apply this page to the live site before the GitHub Release exists.

When the owner has tagged `v1.0.0` and the release assets are public:

1. Point `SITE.githubPrerelease` and `SITE.githubPrereleaseAssets` at `releases/tag/v1.0.0` and `releases/download/v1.0.0`.
2. Set `SITE.version` and `SITE.milestone` to `1.0.0`, and change `statusLabel` from `Release candidate` to `Stable`.
3. Replace download-page archive names and SHA256 lines with the published `goshikq-1.0.0-*` files. Keep the rc.1 and rc.2 checksum records in `docs/release/`.
4. Change README install examples from `-Version v1.0.0-rc.2` / `--version v1.0.0-rc.2` to `v1.0.0`.
5. Change the homepage badge and Playwright checks that require the rc.2 download URL.
6. Leave the Google Search Console token, sitemap, and Bing setup as they are.
7. Do not delete the rc.1 or rc.2 tags or binaries.
8. Registry publication (PyPI, npm, crates.io, Docker) stays a separate approval.
